Syntrometry Interactive Mindmaps

Interactive visualizations of the Syntrometric framework and its mathematical/logical structure, built with "Markmap" (https://markmap.js.org/).

These mindmaps provide a navigable representation of the concepts, definitions, mathematical structures, and relationships developed throughout the project.

🌐 Interactive Website

Explore the mindmaps directly in your browser:

- "Mindmap I — Interactive Website" ([Netlify](https://syntrometry-mindmap.netlify.app)/syntrometry-mindmap.html)
- "Mindmap II — Interactive Website" ([Netlify](https://modernized-syntrometry.netlify.app)/modernized-syntrometry.html)

✨ Features

- Interactive expandable/collapsible nodes
- Mathematical notation rendered with KaTeX
- Hierarchical visualization of complex concepts
- Search and navigation through the mindmap
- Zoom and pan controls
- Browser-based — no installation required
- Self-contained HTML files suitable for local viewing or web deployment

🧮 Subject Matter

The maps cover material related to:

- Burkhard Heim's Syntrometrie
- Syntrometric Logic
- Syntrix and Synkolator structures
- Metroplexes and Syntrixfelder
- Qualia and subjective aspectual structures
- Mathematical and logical foundations
- Modernized Syntrometric Logic (MSL)
- Computational interpretations of the formalism
- Relationships between the various syntrometric structures

🚀 Usage

The HTML files can be opened directly in a modern web browser.

For the best experience, use the hosted versions linked above.

📖 Project

This repository is part of an ongoing effort to transform complex Syntrometric mathematical and logical material into an interactive, navigable computational representation.

The goal is to make the formal structures easier to explore while preserving their hierarchical relationships and mathematical notation.
